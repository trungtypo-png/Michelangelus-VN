==================================================
HƯỚNG DẪN CÀI ĐẶT CHO macOS / macOS INSTALL GUIDE
==================================================

1. Tạo file font:
   Chạy file 'vietnamese_builder.py' ở thư mục gốc (root) để tạo 4 file font TTF tiếng Việt.

2. Cài đặt font vào macOS (1-Click):
   Nhấp đúp chuột vào file 'install.command'.
   (Script sẽ tự động copy font vào thư mục ~/Library/Fonts để sử dụng trên toàn hệ thống).

3. Gỡ cài đặt:
   Nhấp đúp chuột vào file 'uninstall.command'.
