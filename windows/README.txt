==================================================
HƯỚNG DẪN CÀI ĐẶT CHO WINDOWS / WINDOWS INSTALL GUIDE
==================================================

1. Tạo file font:
   Chạy file 'vietnamese_builder.py' ở thư mục gốc (root) để tạo 4 file font TTF tiếng Việt.

2. Cài đặt font vào Windows (1-Click):
   Nhấp đúp chuột vào file 'install.bat'.
   (Script sẽ tự động copy font vào hệ thống, đăng ký Registry và kích hoạt nhận diện font ngay lập tức).

3. Gỡ cài đặt:
   Nhấp đúp chuột vào file 'uninstall.bat'.
