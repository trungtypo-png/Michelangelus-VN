==================================================
HƯỚNG DẪN CÀI ĐẶT CHO WINDOWS / WINDOWS INSTALL GUIDE
==================================================

* CÁCH 1: DÀNH CHO NGƯỜI DÙNG PHỔ THÔNG (NHANH NHẤT - 1 CLICK)
  1. Tải trọn bộ font đã dựng sẵn từ Google Drive:
     👉 https://drive.google.com/drive/folders/1hE8nc5wfGN0kCS44mlHzgg6-QP9CjUdz?usp=sharing
  2. Giải nén và đặt các file font (.ttf) vào thư mục gốc của repo này (hoặc thư mục windows này).
  3. Nhấp đúp chuột vào file 'install.bat'.
     (Script tự động cài font vào hệ thống, đăng ký Registry và kích hoạt nhận diện font ngay lập tức).

* CÁCH 2: TỰ TẠO FONT BẰNG PYTHON (DIY BUILDER)
  1. Đặt 4 file font gốc Microsoft vào repo.
  2. Chạy file 'vietnamese_builder.py' ở thư mục gốc.
  3. Nhấp đúp chuột vào file 'install.bat'.

* ĐỂ GỠ CÀI ĐẶT:
  Nhấp đúp chuột vào file 'uninstall.bat'.
